# Western India Plywoods (WIP) - Boiler Fuel Management & Shift Coordination System
### വെസ്റ്റേൺ ഇന്ത്യ പ്ലേവുഡ്സ് - ബോയിലർ കൺസംഷൻ & ഷിഫ്റ്റ് മാനേജ്‌മെന്റ് സിസ്റ്റം

---

## 📌 അവലോകനം (Overview)
വെസ്റ്റേൺ ഇന്ത്യ പ്ലേവുഡ്സിലെ 3 ബോയിലറുകളുടെയും (**Thermax**, **Max Therm**, **Complock**) ഇന്ധന ഉപയോഗം (Wood Chips, Wood Logs, Plywood Dust) ഷിഫ്റ്റ് അടിസ്ഥാനത്തിലും 24 മണിക്കൂർ ഡെയ്‌ലി അടിസ്ഥാനത്തിലും കൃത്യമായി കണക്കാക്കാനും, 3 ഷിഫ്റ്റുകളിലെ ഓപ്പറേറ്റർമാർക്ക് മൊബൈലിലൂടെ എളുപ്പത്തിൽ ഏകോപിപ്പിക്കാനുമായി തയ്യാറാക്കിയ ആപ്പാണിത്.

---

## ⚙️ ബോയിലറുകളുടെ കണക്കുകൂട്ടൽ രീതി (Boiler Calculation Formulas)

### 1. തെർമാക്സ് ബോയിലർ (Thermax Boiler - Wood Chips)
* **ഇന്ധനം**: വുഡ് ചിപ്സ് (Wood Chips)
* **ബങ്കർ അളവുകൾ**:
  * Upper Rectangular: $508\text{ cm} \times 194\text{ cm} \times 247\text{ cm}$ ($24.342\text{ m}^3$)
  * Lower 2 Hoppers: Height $506\text{ cm}$, Bottom Width $46\text{ cm}$, Top Width $194\text{ cm}$, Length $508\text{ cm}$ ($30.846\text{ m}^3$)
  * ആകെ ബങ്കർ ഡെപ്ത്: $753\text{ cm}$ (Total Capacity: $55.188\text{ m}^3$)
  * Bulk Density: $370\text{ kg/m}^3$ (പൂർണ്ണ കപ്പാസിറ്റി: $20,419.6\text{ kg} \approx 20.42\text{ Tonnes}$)
* **കൺസംഷൻ സമവാക്യം**:
  $$\text{Shift Consumption} = \text{Opening Stock} + \sum (\text{Incoming Lorries}) - \text{Closing Stock}$$
  * ബങ്കർ ഡെപ്ത് $D$ (cm) നൽകുമ്പോൾ തന്നെ വോളിയവും ($m^3$) സ്റ്റോക്കും (Tonnes / kg) തത്സമയം കണക്കാക്കുന്നു.

### 2. മാക്സ് തെർമ് ബോയിലർ (Max Therm Boiler - Logs + Dust)
* **ഇന്ധനം**: വുഡ് ലോഗ്സ് (Wood Logs) + പ്ലൈവുഡ് ഡസ്റ്റ് (Plywood Dust)
* ബങ്കർ ഇല്ല (ഡയറക്റ്റ് ഫീഡിംഗ്).
* **വുഡ് ലോഗ്സ്**: ലോറി വെയ്റ്റ്ബ്രിഡ്ജ് നെറ്റ് വെയ്റ്റ് നേരിട്ട്.
* **പ്ലൈവുഡ് ഡസ്റ്റ്**: ചാക്കുകളുടെ എണ്ണം $\times$ $8\text{ kg}$ (1 ചാക്ക് = 8 kg).
* **കൺസംഷൻ സമവാക്യം**:
  $$\text{Max Therm Consumption} = \text{Wood Logs Weight} + (\text{Dust Sacks} \times 8\text{ kg})$$

### 3. കോംപ്ലോക്ക് ബോയിലർ (Complock Boiler - Wood Logs)
* **ഇന്ധനം**: വുഡ് ലോഗ്സ് മാത്രം (ഡയറക്റ്റ് ഫീഡിംഗ്).
* **കൺസംഷൻ സമവാക്യം**:
  $$\text{Complock Consumption} = \sum (\text{Wood Logs Lorries Net Weight})$$

## ⏰ ഷിഫ്റ്റ് സമയക്രമം (Shift Timings - 24/7)
* **Shift 1**: 06:30 AM – 02:30 PM (Morning)
* **Shift 2**: 02:30 PM – 10:30 PM (Evening)
* **Shift 3**: 10:30 PM – 06:30 AM (Night)

> **✨ ഓട്ടോമാറ്റിക് ഷിഫ്റ്റ് ഹാൻഡ് ഓവർ (Shift Continuity)**:
> ഒരു ഷിഫ്റ്റ് കഴിഞ്ഞ് അടുത്ത ഷിഫ്റ്റ് തിരഞ്ഞെടുക്കുമ്പോൾ, മുൻപത്തെ ഷിഫ്റ്റിലെ Closing Bunker Depth ഓട്ടോമാറ്റിക്കായി പുതിയ ഷിഫ്റ്റിന്റെ Opening Depth ആയി സെറ്റ് ആകും!

## 🚀 ആപ്പ് എങ്ങനെ ഉപയോഗിക്കാം? (How to Run & Use)

### രീതി 1: കമ്പ്യൂട്ടറിലോ മൊബൈലിലോ നേരിട്ട് തുറക്കാൻ (Direct Browser)
* ഫോൾഡറിലുള്ള `index.html` ഫയൽ ഡബിൾ ക്ലിക്ക് ചെയ്ത് ഏതൊരു ബ്രൗസറിലും (Google Chrome, Edge, Safari) തുറക്കാം.
* ഇന്റർനെറ്റ് ഇല്ലാതെ തന്നെ പൂർണ്ണമായും ഓഫ്‌ലൈനായി പ്രവർത്തിക്കും.

### രീതി 2: ലോക്കൽ സെർവർ പ്രവർത്തിപ്പിക്കാൻ (Plant Wi-Fi / Local Network)
* `start-app.bat` ഡബിൾ ക്ലിക്ക് ചെയ്യുക, അല്ലെങ്കിൽ കമാൻഡ് പ്രോംപ്റ്റിൽ നൽകുക:
  ```bash
  agy-node server.js
  ```
* അപ്പോൾ സ്ക്രീനിൽ കാണിക്കുന്ന ഐ.പി അഡ്രസ് (ഉദാ: `http://192.168.x.x:3000`) ഫാക്ടറി വൈഫൈയിലുള്ള ഏത് മൊബൈൽ ഫോണിലും അടിച്ചുകൊടുത്താൽ 3 ഓപ്പറേറ്റർമാർക്കും ഒരേസമയം ഉപയോഗിക്കാം.

### രീതി 3: മൊബൈൽ ഫോണിൽ ആപ്പ് ആയി സൂക്ഷിക്കാൻ (Add to Home Screen)
1. ഫോണിലെ Chrome / Safari ബ്രൗസറിൽ പേജ് തുറക്കുക.
2. ബ്രൗസറിന്റെ മെനുവിൽ (**⋮**) ക്ലിക്ക് ചെയ്യുക.
3. **"Add to Home screen"** (ഹോം സ്ക്രീനിലേക്ക് ചേർക്കുക) നൽകുക.
4. ഇപ്പോൾ ഫോണിൽ മറ്റ് ആപ്പുകളെപ്പോലെ തന്നെ ഒരൊറ്റ ടാപ്പിൽ തുറക്കാം!

## ☁️ ഗൂഗിൾ ഫയർബേസ് ക്ലൗഡ് സിങ്കിങ് (Google Firebase Multi-Phone Live Sync)
വ്യത്യസ്ത ഫോണുകളിൽ വ്യത്യസ്ത ഇന്റർനെറ്റ് കണക്ഷൻ (Jio, Airtel, Wi-Fi മുതലായവ) ഉപയോഗിക്കുന്ന 3 ഷിഫ്റ്റ് ഓപ്പറേറ്റർമാർക്കും തത്സമയം ഒരേ ഡാറ്റ കാണാനും നൽകാനുമുള്ള ഫീച്ചറാണിത്.

### എളുപ്പത്തിൽ സെറ്റപ്പ് ചെയ്യുന്ന വിധം (2 മിനിറ്റ്):
1. [console.firebase.google.com](https://console.firebase.google.com) സന്ദർശിച്ച് നിങ്ങളുടെ Google അക്കൗണ്ട് ഉപയോഗിച്ച് ലോഗിൻ ചെയ്യുക.
2. **"Add project"** ക്ലിക്ക് ചെയ്ത് ഒരു പേര് നൽകുക (ഉദാ: `wip-boiler`). (Google Analytics വേണമെങ്കിൽ ഓഫ് ചെയ്യാം).
3. പ്രോജക്റ്റ് ഡാഷ്‌ബോർഡിൽ ഇടതുവശത്തെ മെനുവിൽ **Build ➜ Firestore Database** തിരഞ്ഞെടുക്കുക.
4. **"Create Database"** ക്ലിക്ക് ചെയ്യുക ➜ **"Start in test mode"** തിരഞ്ഞെടുക്കുക ➜ **Enable** നൽകുക.
5. Project Overview പേജിൽ (മുകളിലെ ⚙️ icon ➜ Project settings) പോയി **Web App (`</>`)** ഐക്കണിൽ ക്ലിക്ക് ചെയ്ത് ആപ്പ് രജിസ്റ്റർ ചെയ്യുക.
6. അവിടെ താഴെ കാണിക്കുന്ന `firebaseConfig` കോഡ് കോപ്പി ചെയ്യുക.
7. ആപ്പിലെ **⚙️ സെറ്റിങ്സ് & ടേബിൾ** ടാബിൽ വന്ന് ഈ കോഡ് പേസ്റ്റ് ചെയ്ത് **⚡ Connect Firebase Cloud** ക്ലിക്ക് ചെയ്യുക!
8. **മറ്റ് രണ്ട് ഓപ്പറേറ്റർമാർക്കും കണക്റ്റ് ചെയ്യാൻ:**
   - താഴെയുള്ള **"📲 Share Setup Link on WhatsApp"** ബട്ടൺ അമർത്തി സഹപ്രവർത്തകർക്ക് WhatsApp-ൽ ലിങ്ക് അയച്ചു കൊടുക്കുക.
   - അവർ സ്വന്തം ഫോണിൽ ആ ലിങ്കിൽ ഒരൊറ്റ ക്ലിക്ക് ചെയ്താൽ മതി, അവരുടെ ഫോണിലും ക്ലൗഡ് സിങ്ക് ഓട്ടോമാറ്റിക്കായി ആക്റ്റിവേറ്റ് ആകും!

## 📲 പ്രധാന ഫീച്ചറുകൾ (Key Features)
1. **തത്സമയ കാൽക്കുലേഷൻ (Live Auto-Calculation)**:
   - ഡെപ്ത് നൽകിയ ഉടൻ കൺസംഷനും ടണ്ണേജും കാൽക്കുലേറ്റ് ആകും.
2. **വിഷ്വൽ ബങ്കർ ഡയഗ്രം (2D Cross-Section SVG)**:
   - ബങ്കറിലെ ചിപ്സിന്റെ ലെവൽ ഗ്രാഫിക്കലായി കാണാം.
3. **One-Tap WhatsApp Share**:
   - ഓരോ ഷിഫ്റ്റിലെയും കൺസംഷൻ മാനേജ്‌മെന്റ് / വാട്സാപ്പ് ഗ്രൂപ്പിലേക്ക് ഒരൊറ്റ ക്ലിക്കിൽ ഷെയർ ചെയ്യാം.
4. **24-Hour Daily Rollup**:
   - 3 ഷിഫ്റ്റുകളുടെയും തുക ചേർത്ത് ദിവസേനയുള്ള ആകെ ഇന്ധന ഉപയോഗം ലഭ്യമാക്കുന്നു.
5. **Excel / CSV Export**:
   - ഓഡിറ്റിനും ഓഫീസിലേക്കുമായി സമ്പൂർണ്ണ ഡാറ്റ ഒറ്റ ക്ലിക്കിൽ എക്സലിലേക്ക് ഡൗൺലോഡ് ചെയ്യാം.
6. **ബാക്കപ്പ് & റീസ്റ്റോർ (Backup & Restore)**:
   - ഡാറ്റ JSON ഫയലായി ബാക്കപ്പ് എടുക്കാനും തിരിച്ചെടുക്കാനും സാധിക്കും.
